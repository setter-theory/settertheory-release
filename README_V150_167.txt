Setter Theory V150.167

【追加内容】
・保存した試合ごとに「チーム再設定」ボタンを追加
・登録済みチームの番号を入力して、過去試合の所属チームを変更可能
・「チーム未設定」へ戻す操作にも対応
・チーム未設定グループ内の全試合を、一括で同じチームへ再設定可能
・再設定したチームID、チーム名、年度を保存データとCSV情報の両方へ反映
・再設定後は保存試合一覧が自動でチーム別に並び直される

【操作方法】
■1試合だけ変更
1. 保存した試合を開く
2. 対象試合の「チーム再設定」を押す
3. 表示された登録チームの番号を入力する

■未設定試合をまとめて変更
1. 「チーム未設定」を開く
2. 「まとめてチーム再設定」を押す
3. 登録チームの番号を入力する
4. 確認画面でOKを押す
