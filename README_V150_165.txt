Setter Theory V150.165

【追加内容】
・保存した試合をチームごとのアコーディオン表示に変更
・チーム名、年度、保存試合数、最新試合日を見出しに表示
・最初のチームだけ最初から開き、ほかのチームは折りたたんで表示
・「チーム未設定」の試合は最後にまとめて表示
・今後保存する試合へチームID、チーム名、年度を固定保存
・登録チームの名称を後から変更しても、過去試合の所属情報を保持
・既存のレポート、PDF、CSV、名前変更、削除ボタンはそのまま維持

【確認ポイント】
1. データ管理から「保存した試合」を開く
2. 保存試合がチームごとに分かれて表示される
3. チーム見出しを押すと開閉する
4. 各試合のレポート・PDF・CSV・名前変更・削除が動く
5. 新しい試合を保存すると、選択中のチーム欄へ入る
