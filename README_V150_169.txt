Setter Theory V150.169

【追加内容】
・チーム管理カードに「このチームで試合設定」ボタンを追加
・登録チームを読み込み、ローテーション設定画面へ直接移動
・登録選手をスタメン6人とベンチへ自動配置
・登録セッター設定を自動反映
・試合開始時のスタメン6人を、そのチームの次回初期スタメンとして保存
・次回以降は前回のスタメン配置を優先して読み込み
・保存試合、集計、PDF、CSVの処理には変更なし

【操作方法】
1. ホームの「チーム・選手管理」を開く
2. 使用するチームの「このチームで試合設定」を押す
3. 相手、開始サーブ、セット番号を確認
4. 必要ならローテーションを入れ替える
5. 「試合開始」を押す
